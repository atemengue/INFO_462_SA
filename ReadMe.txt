********** Projet API *********************

- Installer les prérequis de l'environnement en utilisant la commande    "pip install -r requirements.txt"

- Créer l'utilisateur 'admin' qui va gérer la base de données en utilisant la commande   "python manage.py createsuperuser"
  et suivre les étapes

- Créer les migrations (creation de la base de données) en utilisant successivement les commandes "python manage.py makemigrations" et
  "python manage.py migrate" 

- Lancer le projet en utilisant la commande  ""python manage.py runserver"
